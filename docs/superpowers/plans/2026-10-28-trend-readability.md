# 個人趨勢與結果可讀性計畫

目標：讓固定手機位置下的前後段訊號變化容易閱讀，不把增減當成跑姿評分。

架構：比較計算留在 `lib/gait_engine.dart`，介面留在 `lib/main.dart`，摘要與定義由 `lib/session_recorder.dart` 匯出。保留原始 CSV 欄位與計步器。

使用者條件：手機位置固定。配速、坡度、固定鬆緊仍是可能的干擾。

- [x] 比較第一個可用圖點起算的 30 秒與最近 30 秒。兩段不重疊，各有至少 24 秒可用資料，使用時間加權。

- [x] 步頻差值使用 spm，CV 差值使用百分點，規律性使用原係數差值。幅度只在基準為正時顯示相對百分比，缺值保留空值。

- [x] 候選步頻差異超過 5% 時停止其他動作比較。這是探索性的保護條件，不代表兩段速度相同，也不是生理界線。

- [x] 先顯示變化結果，再顯示圖表。標示視窗、單位、方向及資料不足原因，使用中性文字。收合設定，測試窄螢幕與大字。

- [x] 比較結果與參數加入摘要匯出。測試缺樣、資料不足、零基準、指標缺值及節奏改變。

- [x] Flutter 分析、49 個測試、Android 建置與安裝通過。套件雜湊與手機一致。獨立審查沒有待處理問題。

結果畫面使用明示的測試資料檢查，沒有替換公開研究資料。此次更新時手機鎖定，未新增實機畫面或跑步準確度證據。原始 v0.5 的實機感測檢查另存於驗證紀錄。
