# 功能實作狀態

2026-10-28，v0.8。分析結果是實驗性訊號趨勢，尚無人體動作捕捉準確度驗證。

| 先前討論的四項分析 | 狀態 | 目前範圍 |
|---|---|---|
| 動作狀態時間軸 | 已加入訊號分類 | 靜止訊號、規律移動、其他移動、明顯轉動及不可判讀。未區分走／跑，明顯轉動不等於路線轉彎 |
| 校正後的腰部三向動作分布 | 已加入，有固定條件 | 僅後腰中央。明確選擇螢幕朝向，10 秒準備後直立靜止 5 秒；成功後估計前後／左右／上下 RMS 與平方幅度占比。方向改變或校正失敗時停用方向結果 |
| 腰部旋轉與波形一致性 | 已加入訊號指標 | 全向角速度 RMS 與時間圖、校正方向的平均角速度輔助轉動分類，以及原有加速度規律性。未估計骨盆角度、左右對稱或真實轉彎 |
| 前後段比較 | 已實作，有條件 | 比較候選步頻、幅度、CV 與規律性。候選步頻接近不等於 GPS 配速相同；沒有疲勞診斷 |

結果卡先顯示狀態、各狀態時間、整體動作與旋轉幅度。趨勢圖可展開，校正提示與方向比例使用文字及圖條共同呈現。缺值顯示尚無資料；靜止零幅度不顯示虛構的方向百分比。

在「紀錄設定」啟用三向動作校正，選擇實際螢幕朝向。按開始後有 10 秒可固定手機，接著直立不動 5 秒。校正依賴固定方式假設，沒有偵測到變動也不保證方向一直正確，尤其無法偵測純水平方向的腰帶滑動。前腰與側腰仍可看整體動作及旋轉，不提供三向方向。

原始加速度與陀螺儀各自保留時間戳，沒有依列號合併。新分箱、校正、處理參數及限制記在 summary.json 的 motion_analysis 與 metadata.json 的 motion_analysis_parameters。維持七份匯出檔案及原始 CSV 欄位。

Android v0.7 起支援 health 前景服務與 CPU partial wake lock，使用者開始後允許關屏。服務不會自動啟動或在強制停止後恢復；iOS 仍只在前景錄製。實際測試以 VALIDATION.md 為準。
